# AWS 기초 질문과 답변

## 질문 1. IAM은 무엇이며 왜 필요한가?

- 질문 코드: `202609030107_01`
- 답변 코드: `202609030107_01_답변`

IAM(Identity and Access Management)은 AWS 리소스에 누가 어떤 작업을 어디까지 할 수 있는지 제어하는 서비스입니다. 사용자, 그룹, 역할, 정책을 관리하며 최소 권한 원칙을 적용할 수 있게 합니다. 루트 사용자는 초기 설정과 긴급 상황에만 사용하고 MFA를 설정해야 합니다.

## 질문 2. EC2 인스턴스는 언제 사용해야 하는가?

- 질문 코드: `202609030107_02`
- 답변 코드: `202609030107_02_답변`

Amazon EC2는 가상 서버를 실행하는 서비스입니다. 운영체제와 실행 환경을 직접 제어해야 하는 웹 서버, 자체 설치형 애플리케이션, 오래 실행되는 프로세스에 적합합니다. 생성할 때는 AMI, 인스턴스 유형, EBS 스토리지, 보안 그룹, IAM 역할을 결정합니다. 보안 그룹에는 필요한 포트와 신뢰할 수 있는 접근 경로만 허용합니다.

## 질문 3. Amazon S3는 무엇이고 데이터를 어떻게 보호하는가?

- 질문 코드: `202609030107_03`
- 답변 코드: `202609030107_03_답변`

Amazon S3는 파일을 객체 형태로 버킷에 저장하는 서비스입니다. 이미지, 로그, 백업, 정적 웹 자산 등을 저장할 수 있습니다. 퍼블릭 액세스 차단을 기본으로 유지하고, IAM 정책과 버킷 정책으로 접근을 제한합니다. 민감한 데이터는 암호화하고, 삭제나 덮어쓰기에 대비해야 하면 버전 관리를 사용합니다.

## 질문 4. VPC는 무엇이며 서브넷과 보안 그룹은 어떤 역할을 하는가?

- 질문 코드: `202609030107_04`
- 답변 코드: `202609030107_04_답변`

VPC는 AWS 안에서 만드는 논리적으로 분리된 가상 네트워크입니다. 서브넷은 VPC의 IP 주소 범위를 나눈 네트워크 구역이며 하나의 가용 영역에 속합니다. 보안 그룹은 EC2 같은 리소스에 연결하는 상태 저장 방식의 가상 방화벽입니다. 외부에 공개할 웹 계층은 퍼블릭 서브넷에, 데이터베이스처럼 공개할 필요가 없는 리소스는 프라이빗 서브넷에 배치합니다.

## 질문 5. AWS Lambda는 무엇이며 어떤 상황에 적합한가?

- 질문 코드: `202609030107_05`
- 답변 코드: `202609030107_05_답변`

AWS Lambda는 서버를 직접 관리하지 않고 이벤트에 따라 코드를 실행하는 서버리스 컴퓨팅 서비스입니다. S3 파일 업로드 처리, API 처리, 일정 기반 자동화, 메시지 처리 등에 적합합니다. 필요한 IAM 권한만 부여하고, 비밀 값은 Secrets Manager나 Parameter Store로 관리하며, 실패 처리와 모니터링도 함께 설계합니다.
