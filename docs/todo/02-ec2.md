# 질문 2. EC2 인스턴스는 언제 사용해야 하는가?

## 답변

Amazon EC2(Elastic Compute Cloud)는 AWS에서 가상 서버를 실행하는 서비스입니다. 운영체제, CPU, 메모리, 네트워크 설정을 비교적 자유롭게 선택하고 관리해야 하는 워크로드에 적합합니다.

웹 서버, 자체 설치형 애플리케이션, 특정 에이전트가 필요한 배치 작업, 오래 실행되는 프로세스 등이 대표적인 사용 사례입니다. 반대로 서버 관리가 부담스럽고 요청 단위 실행만 필요하다면 Lambda나 컨테이너 기반 서비스를 먼저 검토할 수 있습니다.

## 인스턴스 생성 시 결정할 것

- **AMI**: 인스턴스의 운영체제와 기본 소프트웨어 이미지
- **인스턴스 유형**: CPU, 메모리, 네트워크 성능 조합
- **스토리지(EBS)**: 운영체제와 데이터를 저장할 디스크
- **보안 그룹**: 인스턴스의 인바운드·아웃바운드 네트워크 규칙
- **IAM 역할**: 인스턴스가 다른 AWS 서비스에 접근할 권한

## 운영 원칙

보안 그룹에는 필요한 포트와 신뢰할 수 있는 출발지만 허용합니다. SSH(22)나 RDP(3389)를 전체 인터넷에 열지 않는 것이 좋습니다. 인스턴스 유형과 구매 옵션은 사용량에 따라 선택하고, 중지하지 않은 인스턴스와 연결된 스토리지에도 비용이 발생할 수 있음을 확인합니다.
