# 질문 5. AWS Lambda는 무엇이며 어떤 상황에 적합한가?

## 답변

AWS Lambda는 서버를 직접 프로비저닝하거나 관리하지 않고 코드를 실행하는 서버리스 컴퓨팅 서비스입니다. 파일 업로드, HTTP 요청, 메시지 도착, 일정 등 이벤트가 발생하면 함수를 실행하고, 사용한 실행 시간과 요청 수를 기준으로 비용이 발생합니다.

## 적합한 사용 사례

- S3에 파일이 올라오면 이미지 크기를 변환하는 작업
- API Gateway 뒤에서 간단한 API 처리
- EventBridge 일정에 따른 자동화 및 배치 작업
- SQS, DynamoDB 같은 서비스 이벤트를 처리하는 비동기 작업

## EC2와의 차이

EC2는 서버 운영체제와 실행 환경을 계속 관리하는 대신 제어 범위가 넓습니다. Lambda는 실행 환경 관리 부담이 작고 이벤트 기반으로 자동 확장되지만, 함수 실행 시간·패키지·네트워크 구성 등의 제약을 고려해야 합니다. 오래 유지되는 연결이나 지속적으로 큰 컴퓨팅 자원이 필요한 작업은 EC2 또는 컨테이너 서비스가 더 적합할 수 있습니다.

## 운영 원칙

함수마다 필요한 IAM 권한만 부여하고, 환경 변수에 비밀 값을 직접 넣기보다 Secrets Manager나 Parameter Store를 사용합니다. 오류 재시도, 실패 이벤트 처리(DLQ 또는 대상), 로그와 지표 모니터링을 함께 설계해야 안정적으로 운영할 수 있습니다.
