# 질문 1. IAM은 무엇이며 왜 필요한가?

## 답변

IAM(Identity and Access Management)은 AWS 리소스에 **누가**, **어떤 작업을**, **어디까지** 할 수 있는지 제어하는 서비스입니다. AWS 계정의 사용자, 그룹, 역할(Role), 정책(Policy)을 관리합니다.

예를 들어 개발자에게는 EC2를 조회하고 배포할 권한을 주되, 결제 정보 변경 권한은 주지 않을 수 있습니다. 애플리케이션이 S3에 파일을 저장해야 할 때도 장기 액세스 키 대신 IAM 역할을 부여해 필요한 S3 권한만 갖도록 만듭니다.

## 핵심 개념

- **사용자(User)**: 사람 또는 개별 작업 주체를 나타낸다.
- **그룹(Group)**: 비슷한 권한이 필요한 사용자를 묶는다.
- **역할(Role)**: 사람이나 AWS 서비스가 일시적으로 맡는 권한 묶음이다.
- **정책(Policy)**: 허용 또는 거부할 AWS 작업과 리소스를 JSON으로 정의한다.

## 왜 중요한가?

IAM은 최소 권한 원칙을 적용해 실수와 보안 사고의 범위를 줄입니다. 모든 사람이 루트 사용자로 작업하면 계정 전체가 위험해질 수 있으므로, 루트 사용자는 초기 설정과 긴급 상황에만 사용하고 MFA를 설정해야 합니다.

## 실천 항목

1. 루트 사용자에 MFA를 설정한다.
2. 일상 작업에는 IAM 사용자 또는 IAM Identity Center를 사용한다.
3. 필요한 작업만 허용하는 정책을 작성한다.
4. 액세스 키를 코드나 Git 저장소에 저장하지 않는다.
