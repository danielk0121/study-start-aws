# 질문 4. VPC는 무엇이며 서브넷과 보안 그룹은 어떤 역할을 하는가?

## 답변

VPC(Virtual Private Cloud)는 AWS 계정 안에서 정의하는 논리적으로 분리된 가상 네트워크입니다. IP 주소 범위, 서브넷, 라우팅, 인터넷 연결, 네트워크 보안 규칙을 직접 구성할 수 있습니다.

## 핵심 구성 요소

- **서브넷(Subnet)**: VPC의 IP 주소 범위를 더 작게 나눈 네트워크 구역이다. 하나의 가용 영역(AZ)에 속한다.
- **라우팅 테이블**: 목적지 트래픽을 어디로 보낼지 결정한다.
- **인터넷 게이트웨이**: VPC와 인터넷 사이의 통신을 가능하게 한다.
- **보안 그룹(Security Group)**: EC2 같은 리소스에 연결하는 상태 저장 방식의 가상 방화벽이다.
- **네트워크 ACL**: 서브넷 단위로 적용하는 상태 비저장 방식의 추가 네트워크 필터다.

## 퍼블릭 서브넷과 프라이빗 서브넷

인터넷 게이트웨이로 향하는 경로가 있는 서브넷을 일반적으로 퍼블릭 서브넷이라고 합니다. 인터넷에서 직접 접근할 웹 계층을 여기에 둘 수 있습니다. 데이터베이스처럼 외부에 노출할 필요가 없는 리소스는 프라이빗 서브넷에 배치하고, 필요한 경우 NAT를 통해 외부로 나가는 통신만 허용합니다.

## 설계 원칙

역할에 따라 네트워크를 나누고, 보안 그룹은 IP 범위보다 다른 보안 그룹을 참조하는 규칙을 우선 검토합니다. 또한 여러 가용 영역에 리소스를 분산하면 장애 대응력을 높일 수 있습니다.
