# 질문 3. Amazon S3는 무엇이고 데이터를 어떻게 보호하는가?

## 답변

Amazon S3(Simple Storage Service)는 파일을 객체(Object) 형태로 저장하는 서비스입니다. 객체는 버킷(Bucket) 안에 저장되며, 이미지·로그·백업·정적 웹 사이트 자산·데이터 분석용 원본 파일 등에 사용됩니다.

폴더처럼 보이는 경로는 실제 디렉터리가 아니라 객체 키(Key)의 접두사입니다. S3는 서버의 일반 디스크처럼 파일을 임의로 수정하기보다, 객체를 업로드·조회·교체하는 방식으로 사용합니다.

## 데이터를 보호하는 방법

- **퍼블릭 액세스 차단**을 기본값으로 유지한다.
- IAM 정책과 버킷 정책으로 필요한 주체에만 접근을 허용한다.
- 민감한 데이터에는 서버 측 암호화를 적용한다.
- 실수로 삭제하거나 덮어쓰는 위험이 있으면 버전 관리(Versioning)를 활성화한다.
- 오래된 데이터는 수명 주기(Lifecycle) 규칙으로 저비용 스토리지 클래스로 이동하거나 삭제한다.

## 주의 사항

버킷 이름은 전역적으로 고유해야 하며, 버킷과 객체의 리전·전송·저장 용량에 따라 비용이 달라집니다. 공개 배포가 꼭 필요하다면 공개 버킷 대신 CloudFront와 제한된 원본 접근 방식을 우선 고려합니다.
