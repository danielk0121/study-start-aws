# AWS 시작 학습

AWS의 주요 리소스와 서비스를 질문·답변으로 학습하는 프로젝트입니다. 컴퓨팅, 데이터베이스, 스토리지, 네트워킹, 서버리스, 모니터링 등 역할별 서비스의 특징과 과금 조건을 정리합니다.

프로젝트 전역 작성 규칙은 [프로젝트-규칙.md](프로젝트-규칙.md)에서 확인할 수 있습니다.

## 학습 목표

- AWS 리소스 종류와 특징을 이해한다.
- 각 리소스와 사용 조건에 따른 과금 특징을 이해한다.
- 컴퓨팅, 데이터베이스, 스토리지, 네트워킹, 서버리스, 모니터링 등 AWS 서비스를 역할별로 구분해 이해한다.
- 모든 AWS 학습 내용은 AWS 공식 문서를 기반으로 학습한다.

## 문서 진행 상태

`docs/`는 Markdown 문서만 보관하며, 학습 진행 상태에 따라 다음 네 폴더로 관리합니다.

| 폴더 | 의미 |
| --- | --- |
| `todo/` | 아직 시작하지 않은 문서 |
| `doing/` | 현재 작업 중인 문서 |
| `hold/` | 시작했지만 현재 진행하지 않는 문서 |
| `done/` | 완료된 문서. 필요하면 다른 상태의 문서에서 참고할 수 있음 |

질문 문서는 진행 상태에 따라 `todo/`, `doing/`, `hold/`, `done/` 중 한 폴더에 둡니다. 답변 문서는 상태 폴더에 두지 않고 `results/`에만 보관합니다.

## 학습 방법

1. `docs/todo/`의 문서를 순서대로 읽는다.
2. 각 질문에 자신의 말로 먼저 답한 뒤 문서의 답변과 비교한다.
3. AWS 공식 문서를 우선 참고해 서비스 기능, 사용 조건, 과금 정보를 확인한다.
4. AWS 콘솔 또는 CLI에서 무료 사용 범위와 비용을 확인한 뒤, 작은 실습으로 개념을 검증한다.
5. 진행 상태가 바뀌면 문서를 해당 상태 폴더로 옮긴다.

## 이미지 자료

스크린샷과 다이어그램 등 Markdown 문서에서 참조하는 이미지 자료는 `asserts/` 폴더에 저장합니다. 문서에서는 이미지 파일을 상대 경로로 참조합니다.

```md
![설명](../../asserts/이미지-파일명.png)
```

## 학습 결과

학습을 마친 답변 문서는 `results/`에 보관합니다. 답변 파일명은 `묶음번호-질문번호-주제.md` 형식으로 작성합니다. 예를 들어 첫 번째 질문 묶음의 IAM 답변은 `001-01-IAM.md`입니다.

각 답변 파일의 첫 줄에는 답변할 질문을 제목으로 작성합니다. [목차](results/목차.md)에서 저장된 답변을 확인할 수 있습니다.

## 폴더 구조

```text
.
├── README.md
├── asserts/                  # 문서에서 참조하는 이미지 자료
│   └── 이미지-안내.md
├── docs/
    ├── todo/                 # 아직 시작하지 않음
    │   └── 001-AWS-기초-질문.md  # 질문 5개
    ├── doing/                # 작업 중
    │   └── 안내.md
    ├── hold/                 # 시작했으나 현재 보류
    │   └── 안내.md
    └── done/                 # 완료, 다른 문서에서 참고 가능
        └── 안내.md
└── results/                  # 완료된 학습 결과
    ├── 목차.md
    ├── 001-01-IAM.md
    ├── 001-02-EC2.md
    ├── 001-03-S3.md
    ├── 001-04-VPC.md
    └── 001-05-Lambda.md
```

> 실습 후에는 사용하지 않는 리소스를 반드시 삭제하고, 실제 비용이 발생할 수 있는 서비스는 요금 페이지와 예산 알림을 먼저 확인합니다.
