# Start AWS

AWS의 핵심 서비스를 질문과 답변으로 학습하는 프로젝트입니다. 각 문서는 한 가지 주제를 중심으로 핵심 개념, 사용 시점, 보안 및 운영 시 유의할 점을 정리합니다.

## 학습 목표

- AWS 계정과 리소스를 안전하게 관리하는 방법을 이해한다.
- 컴퓨팅, 스토리지, 네트워킹, 서버리스 서비스의 역할을 구분한다.
- 서비스 선택 시 고려할 기본적인 보안과 비용 원칙을 익힌다.

| 5 | AWS Lambda는 무엇이며 어떤 상황에 적합한가? | [docs/05-lambda.md](docs/05-lambda.md) |

## 학습 방법

1. `docs/`의 문서를 순서대로 읽는다.
2. 각 질문에 자신의 말로 먼저 답한 뒤 문서의 답변과 비교한다.
3. AWS 콘솔 또는 CLI에서 무료 사용 범위와 비용을 확인한 뒤, 작은 실습으로 개념을 검증한다.
